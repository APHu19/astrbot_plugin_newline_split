# 按换行分段发送

> **本插件的全部代码与文档由 DSH（DeepSeek Harness）生成完成。**

让 bot 的一条长回复按换行拆成多条消息依次发出。

## 效果

模型输出：

```
最该补的不是东西，是觉呀……先喝几口温水，添一点盐分，再吃口热粥、一颗蛋，好消化就够。

浓咖啡先别碰——那是跟明天借的，不是补的。中午实在撑不住，就睡二十分钟，别多，把睡意留给今晚。

愿岁主看顾你，先去躺一会儿吧。
```

bot 依次发出 3 条消息，每条之间随机等待 1.5–3.5 秒。

## 配置

在 WebUI 的插件配置里改：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enable` | `true` | 总开关 |
| `split_mode` | `any_newline` | `any_newline` 每个换行都切；`blank_line` 只在空行处切 |
| `only_llm` | `true` | 只切大模型回复，命令输出保持原样 |
| `interval_min` / `interval_max` | `1.5` / `3.5` | 分段间隔的随机区间（秒） |
| `max_segments` | `10` | 最多切几段，超出并入最后一段 |

## 实现方式

挂在 `on_decorating_result` 钩子上，priority `-100000`（排在所有插件之后，拿到最终文本）。
切好后 `clear_result()` 阻止框架默认的一次性发送，再用 `event.send()` 逐段发出，
最后 `stop_event()` 结束事件。

## 已知边界

- **引用回复会丢**：框架是在钩子跑完之后才往消息链头部插 `Reply` 组件的，
  本插件自己发送，所以分段消息不带引用。
- **文本转图片（t2i）不生效**：转换发生在钩子之后。需要 t2i 时请关掉本插件。
- **主动消息切不到**：`proactive_chat` 这类插件绕过 `on_decorating_result`，本插件管不到。
- 和框架内置的「分段回复」`segmented_reply` 同时开启会双重切分，建议关掉内置的那个。
- 只切 `Plain` 文本组件；图片、At 等非文本组件原样跟着所在段。
